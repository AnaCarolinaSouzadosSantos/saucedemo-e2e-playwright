# SauceDemo E2E - Automação com Playwright & TypeScript

Projeto de testes automatizados End-to-End (E2E) da aplicação [SauceDemo](https://www.saucedemo.com/), estruturado com **Page Object Model (POM)**.

## Pré-requisitos
- Node.js (v18+)
- Git

## Instalação
```bash
git clone https://github.com/AnaCarolinaSouzadosSantos/saucedemo-e2e-playwright.git (https://github.com/AnaCarolinaSouzadosSantos/saucedemo-e2e-playwright.git)
cd saucedemo-e2e-playwright
npm install
npx playwright install
